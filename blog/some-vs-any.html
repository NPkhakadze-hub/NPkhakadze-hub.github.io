some თუ any — წესი, გამონაკლისები და ხშირი შეცდომა 🍵

22 აგვისტო, 2026 · ნოდარი

„ფული მაქვს“ — ქართულად ამ წინადადებაში არც some გვჭირდება და არც any. ინგლისურად კი სამ სხვადასხვა სიტუაციაში სამი სხვადასხვა ვარიანტია: I have some money. Do you have any money? I don't have any money. სწორედ ამიტომ ერევა ხოლმე ბევრს — წესი თითქოს იცი, მაგრამ ლაპარაკისას პირველი, რაც ენაზე მოგადგება, იმას ამბობ.

კარგი ამბავი ისაა, რომ წესი მოკლეა, გამონაკლისი კი სულ ორი. ქვემოთ ორივეს გავივლით, ქართულთანაც შევადარებთ და ბოლოს თავსაც შეამოწმებ.

საბაზისო წესი: some / any

✅ some → მტკიცებითში: I have some money. — ფული მაქვს (რაღაც რაოდენობის).
✅ any → უარყოფაში: I don't have any money. — ფული არ მაქვს.
✅ any → კითხვაში: Do you have any money? — ფული გაქვს?

ორივე იხმარება როგორც უთვლად არსებითთან (money, water, time), ისე მრავლობით დათვლადთან (friends, questions, apples): some friends, any questions. ქართულ თარგმანში ხშირად არც ჩანს — „ფული მაქვს“, „კითხვები გაქვს?“ — და სწორედ ამიტომ გვავიწყდება ხოლმე.

❌ I don't have some money.
✅ I don't have any money. — ფული არ მაქვს.
✅ I have no money. — იგივე აზრი, ოღონდ don't-ის გარეშე.

ანუ უარყოფა ორნაირად გამოიხატება: not … any ან no. ორივე ერთად — არა (ამას ქვემოთ დავუბრუნდებით). any ჩნდება არა მხოლოდ not-ის, არამედ სხვა „უარყოფითი“ სიტყვების შემდეგაც — never, hardly, without — და if-ის შემდეგაც:

✅ She left without any explanation. — ყოველგვარი ახსნის გარეშე წავიდა.
✅ There's hardly any milk left. — რძე თითქმის აღარ არის.
✅ If you have any questions, just ask. — თუ რამე კითხვა გაქვს, მკითხე.

გამონაკლისი №1: some კითხვაში — შეთავაზება და თხოვნა

კითხვაში some მაშინ ჩნდება, როცა სინამდვილეში არაფერს ეკითხები — სთავაზობ ან ითხოვ და „კი“-ს ელოდები.

✅ Would you like some tea? — ჩაი ხომ არ გინდა? (შეთავაზება)
✅ Can I have some water, please? — წყალი შეიძლება? (თხოვნა)
✅ Could you lend me some money? — ფულს ხომ არ მასესხებ?

ახლა შეადარე ორი თითქმის ერთნაირი კითხვა:

✅ Do you have any questions? — კითხვები გაქვს? (ნეიტრალური: არ ვიცი, გაქვს თუ არა)
⚠️ Do you have some questions? — შეცდომა არ არის! ასე მაშინ იტყვი, როცა ხედავ, რომ კითხვები ნამდვილად აქვს: „რაღაც კითხვები გაქვს, ხომ?“

ანუ Do you have some…? გრამატიკულად სწორია — უბრალოდ სხვა ელფერი აქვს. თუ ეჭვი გეპარება, კითხვაში any უსაფრთხო არჩევანია, some კი შეთავაზებისა და თხოვნისთვის დაიტოვე. (ბრიტანულში ხშირად გაიგონებ Have you got any…? — მნიშვნელობა იგივეა, რაც Do you have any…?)

გამონაკლისი №2: any მტკიცებითში = „ნებისმიერი“

✅ Any time is fine. — ნებისმიერი დრო მაწყობს.
✅ You can take any bus — they all go to the station. — ნებისმიერ ავტობუსში ჩაჯექი.
✅ Anyone can learn this. — ამის სწავლა ნებისმიერს შეუძლია.

ამ მნიშვნელობით any მხოლობით დათვლად არსებითსაც ერთვის (any bus, any time). მარტივი შემოწმება: თუ ქართულად „ნებისმიერი“ ჯდება, ინგლისურად any გჭირდება — მტკიცებითშიც.

someone / anyone, something / anything, somewhere / anywhere

ნაწარმოები სიტყვები იმავე წესს მიჰყვება:

✅ Someone called you. — ვიღაცამ დაგირეკა. · Did anyone call? — ვინმემ დარეკა?
✅ I bought something. — რაღაც ვიყიდე. · I didn't buy anything. — არაფერი მიყიდია.
✅ My keys are somewhere in the car. — გასაღები სადღაც მანქანაშია. · I can't find them anywhere. — ვერსად ვპოულობ.

აქ ქართული კარგად გეხმარება: ვიღაც / რაღაც / სადღაც ≈ someone / something / somewhere, ვინმე / რამე / სადმე ≈ anyone / anything / anywhere. „ვიღაცამ დარეკა“ ფაქტია — someone; „ვინმემ დარეკა?“ კითხვაა — anyone. შესაბამისობა სრული არ არის, მაგრამ ორიენტირად გამოდგება. შეთავაზებაშიც იგივე გამონაკლისი მოქმედებს: Would you like something to drink?

არსებობს უარყოფითი ფორმებიც — nothing, no one / nobody, nowhere. ისინი უკვე შეიცავს უარყოფას, ამიტომ ზმნა მტკიცებითი რჩება: I saw nobody. = I didn't see anybody.

ხშირი შეცდომა: ორმაგი უარყოფა

❌ I didn't see nobody.
✅ I didn't see anybody. — არავინ მინახავს.
✅ I saw nobody. — იგივე აზრი.

ქართულად ორმაგი უარყოფა ნორმაა — „არავინ არ მინახავს“, „არაფერი არ ვიყიდე“ — და სწორედ ამას გადმოვიტანთ ხოლმე ინგლისურში. სტანდარტულ ინგლისურში კი წინადადებაში ერთი უარყოფა კმარა: ან not … any-, ან no-. (ზოგ დიალექტსა და სიმღერაში I don't need nobody გაიგონებ, მაგრამ გამოცდაზე, სამსახურსა და წერილში ეს შეცდომად ითვლება.)

❌ I don't want nothing.
✅ I don't want anything. — არაფერი არ მინდა.
❌ There isn't some milk in the fridge.
✅ There isn't any milk in the fridge. — მაცივარში რძე არ არის.

შეამოწმე თავი

სიტყვების ბანკი: some · any · someone · anyone · somewhere · anywhere

1. Sorry, I can't help you today — I don't have ___ time.
2. Can I have ___ sugar in my coffee, please?
3. ___ time is fine — I'm free all day.
4. There's ___ in the kitchen — I can hear footsteps.
5. I looked everywhere, but I couldn't find my glasses ___.
6. I didn't tell ___ about it — it's a secret.

პასუხები: 1. any — უარყოფა. 2. some — თხოვნა. 3. Any — „ნებისმიერი“. 4. someone (somebody-ც სწორია) — მტკიცებითი. 5. anywhere — უარყოფა. 6. anyone (anybody-ც სწორია) — და არა nobody: ორმაგი უარყოფა არ გვინდა.

ერთი პრაქტიკული რჩევა: რამდენიმე დღე ყურადღება მიაქციე, როგორ ამბობ „არ მაქვს“-ს — ყოველი I don't have…, რომელსაც უთვლადი ან მრავლობითი არსებითი მოსდევს (time, money, friends), any-თ დაამთავრე — მხოლობით დათვლადთან კი a/an რჩება: I don't have a car. ეს ერთი ჩვევა ერთ-ერთ ყველაზე ხშირ შეცდომას აქრობს. შემდეგი ბუნებრივი ნაბიჯი რაოდენობის სხვა სიტყვებია — much, many და a lot of — და არტიკლები a/an/the, რომლებიც some tea-ს ნაცვლად a cup of tea-სთვის გჭირდება. თუ ასეთი წესების ცოცხალ საუბარში გავარჯიშება გინდა, ინგლისურის ინდივიდუალური ონლაინ გაკვეთილები სწორედ ამისთვისაა.

ხშირი კითხვები

რა განსხვავებაა some-სა და any-ს შორის?

some მტკიცებით წინადადებაში იხმარება (I have some money), any — უარყოფასა და კითხვაში (I don't have any money. Do you have any money?). ორივე უთვლად არსებითთანაც გამოდგება და მრავლობით დათვლადთანაც.

როდის იხმარება some კითხვაში?

როცა რაღაცას სთავაზობ ან ითხოვ და „კი“-ს ელოდები: Would you like some tea? Can I have some water? ნეიტრალურ კითხვაში, სადაც პასუხი არ იცი, any ჯობია: Do you have any questions?

შეიძლება any მტკიცებით წინადადებაში?

კი, მაშინ, როცა „ნებისმიერი“ იგულისხმება: Any time is fine. You can take any bus. ამ მნიშვნელობით any მხოლობით არსებითსაც ერთვის.

სწორია „I didn't see nobody“?

სტანდარტულ ინგლისურში არა — ეს ორმაგი უარყოფაა. სწორია I didn't see anybody ან I saw nobody. ქართულად „არავინ არ მინახავს“ ნორმაა, ინგლისურში კი წინადადებაში ერთი უარყოფა კმარა.
