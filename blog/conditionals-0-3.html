Conditionals ქართულად — პირობითი წინადადებები ინგლისურში ერთ გვერდზე 🔀

11 სექტემბერი, 2026 · ნოდარი

If I will have time… — ეს ფრაზა თითქმის ყველა ქართველი მოსწავლისგან მსმენია და სრულიად ლოგიკურიცაა: ქართულად ხომ „თუ დრო მექნება“ ვამბობთ, მომავალი დროით. ინგლისური კი აქ სხვა წესს მიჰყვება — და სწორედ ამიტომაა პირობითი წინადადებები ერთ-ერთი ყველაზე დამაბნეველი თემა.

სინამდვილეში ოთხივე ტიპი ერთ ლოგიკას ემორჩილება: რამდენად რეალურია პირობა და რომელ დროს ეხება. ქვემოთ თითოეულს ცალ-ცალკე განვიხილავთ, ბოლოს კი ერთ სიაში მოვუყრით თავს, რომ ერთი შეხედვით გაარჩიო.

ამ სტატიაში
  1. რისგან შედგება პირობითი წინადადება
  2. Zero conditional — რაც ყოველთვის ასეა
  3. First conditional — რეალური მომავალი
  4. Second conditional — წარმოსახვითი აწმყო
  5. Third conditional — წარსული, რომელიც აღარ შეიცვლება
  6. ოთხივე ერთ სიაში
  7. რას გვეუბნება ქართული — და სად გვატყუებს
  8. Mixed conditional — როცა წარსული აწმყოს ეხება
  9. შეამოწმე თავი

რისგან შედგება პირობითი წინადადება

ყოველ პირობით წინადადებას ორი ნაწილი აქვს: პირობა (if-ნაწილი) და შედეგი (მთავარი წინადადება). თანმიმდევრობა თავისუფალია — შეგიძლია if-ით დაიწყო ან შედეგით. ერთი პუნქტუაციური წესი: როცა if-ნაწილი წინ დგას, მას მძიმე მოსდევს; როცა უკან — მძიმე არ სჭირდება.

✅ If it rains, we'll stay at home. — თუ იწვიმებს, სახლში დავრჩებით.
✅ We'll stay at home if it rains. — იგივე, ოღონდ მძიმის გარეშე.

ტიპებს ერთმანეთისგან ის განასხვავებს, თუ რა დრო დგას ამ ორ ნაწილში — ანუ „ფორმულა“. სულ ოთხი ძირითადი ფორმულაა და თითოეული განსხვავებულ სიტუაციას ემსახურება.

Zero conditional — რაც ყოველთვის ასეა

ფორმულა: If + Present Simple, Present Simple.

ეს ტიპი ფაქტებზე, ბუნების კანონებსა და ჩვევებზეა. აქ if თითქმის იგივეა, რაც when — „როცა“: შედეგი ყოველ ჯერზე ერთი და იგივეა.

❌ If you will heat ice, it melts.
✅ If you heat ice, it melts. — ყინულს თუ გაათბობ, დნება.
✅ If I drink coffee late, I don't sleep well. — გვიან ყავას თუ დავლევ, კარგად ვერ ვიძინებ.
⚠️ If you heat ice, it will melt. — ესეც სწორია, მაგრამ უკვე first conditional-ია: არა ზოგადი კანონი, არამედ კონკრეტული შემთხვევა.

💡 ინდივიდუალურად: 📝 ეროვნული გამოცდები → · წაიკითხე: Present Perfect თუ Past Simple — როგორ ავირჩიოთ სწორი დრო

First conditional — რეალური მომავალი

ფორმულა: If + Present Simple, will + ზმნა.

პირობა რეალურია და მომავალს ეხება: შეიძლება მოხდეს, შეიძლება — არა. სწორედ აქ იბადება ქართველების ყველაზე ხშირი შეცდომა. ქართულად ორივე ნაწილი მომავალშია — „თუ დრო მექნება, დაგირეკავ“ — და ხელი თავისით will-ს ორჯერ წერს. ინგლისურში კი if-ის შემდეგ მომავლის აზრს Present Simple გადმოსცემს, will მხოლოდ შედეგშია.

❌ If I will have time, I will call you.
✅ If I have time, I'll call you. — თუ დრო მექნება, დაგირეკავ.
❌ If it will rain tomorrow, we will cancel the trip.
✅ If it rains tomorrow, we'll cancel the trip. — ხვალ თუ იწვიმებს, მოგზაურობას გავაუქმებთ.

შედეგში will-ის ნაცვლად შეიძლება იდგეს can, might, should ან ბრძანება: If you see Ana, tell her to call me. წესი მხოლოდ if-ნაწილს ეხება — იქ will არ დგას. იგივე წესი მოქმედებს when-ზე, as soon as-ზე და until-ზე. ერთი იშვიათი გამონაკლისი არსებობს — If you'll wait a moment, I'll check — მაგრამ აქ will მომავალი კი არა, თავაზიანი თხოვნაა. ჯერ ძირითადი წესი დაიმახსოვრე.

Second conditional — წარმოსახვითი აწმყო

ფორმულა: If + Past Simple, would + ზმნა.

აქ Past Simple წარსულს კი არ ნიშნავს, არამედ „არარეალურობას“: სიტუაცია აწმყოს ან მომავალს ეხება, მაგრამ ან შეუძლებელია, ან ნაკლებად სავარაუდო. ქართულში ეს ზუსტად „რომ“ + კავშირებითი კონსტრუქციაა: „მეტი ფული რომ მქონდეს, მანქანას ვიყიდდი“.

მეორე დიდი შეცდომა სწორედ აქ ჩნდება — would if-ნაწილშიც გადადის. ქართული „ვიცოდე“ თითქოს would know-ს ჰგავს, მაგრამ ინგლისურად if-ის შემდეგ would არ დგას. მარტივი შემოწმება: would მხოლოდ შედეგშია, if-ის შემდეგ — ჩვეულებრივი Past Simple.

❌ If I would know the answer, I would tell you.
✅ If I knew the answer, I'd tell you. — პასუხი რომ ვიცოდე, გეტყოდი.
❌ If I would have more time, I would learn Spanish.
✅ If I had more time, I'd learn Spanish. — მეტი დრო რომ მქონდეს, ესპანურს ვისწავლიდი.

ზმნა be ამ ტიპში სტანდარტულ ინგლისურში ყველა პირში were-ის ფორმით დგას — ამიტომ If I were you. სასაუბრო ინგლისურში If I was you-საც გაიგონებ, მაგრამ წერაში და გამოცდაზე were უსაფრთხო არჩევანია.

⚠️ If I was you, I'd take the job. — სასაუბროდ გავრცელებულია, მაგრამ არაფორმალურია.
✅ If I were you, I'd take the job. — შენს ადგილას რომ ვიყო, ამ სამსახურზე დავთანხმდებოდი.

Third conditional — წარსული, რომელიც აღარ შეიცვლება

ფორმულა: If + Past Perfect, would have + V3 (ზმნის მესამე ფორმა).

ეს ტიპი წარსულზეა — იმაზე, რაც არ მოხდა და რასაც ვეღარ შეცვლი: სინანული, ახსნა, „ნეტავ“. ქართულად ეს არის „რომ მცოდნოდა“, „რომ წამოსულიყო“ — მეორე თურმეობითი, წარსულის არარეალური ფორმა.

ფორმულა ყველაზე გრძელია, ამიტომ შეცდომაც ორნაირია: ან would if-ნაწილში შედის (If I would have known), ან Past Perfect-ის ნაცვლად უბრალო Past Simple რჩება (If I knew — რაც უკვე second conditional-ია და აწმყოს ნიშნავს).

❌ If I would have known, I would have come earlier.
✅ If I had known, I'd have come earlier. — რომ მცოდნოდა, უფრო ადრე მოვიდოდი.
❌ If I studied harder last year, I would have passed the exam.
✅ If I had studied harder last year, I'd have passed the exam. — შარშან მეტი რომ მემეცადინა, გამოცდას ჩავაბარებდი.

სასაუბროდ had და would ორივე 'd-ად იკუმშება: If I'd known, I'd have come. ყური შეაჩვიე, ეს ორი 'd ერთმანეთში რომ არ აგერიოს — პირველი had-ია, მეორე would.

ოთხივე ერთ სიაში

  • Zero — If + Present Simple, Present Simple. ფაქტი, კანონი, ჩვევა. If you heat ice, it melts.
  • First — If + Present Simple, will + ზმნა. რეალური მომავალი. If it rains, we'll stay at home.
  • Second — If + Past Simple, would + ზმნა. წარმოსახვითი აწმყო / მომავალი. If I had more time, I'd learn Spanish.
  • Third — If + Past Perfect, would have + V3. არარეალური წარსული. If I had known, I'd have come.

მთელი სია ერთ წესამდე დაიყვანება: if-ის შემდეგ, როგორც წესი, არც will დგას, არც would. თუ ეს ერთი რამ დაიმახსოვრე, ზემოთ ჩამოთვლილი შეცდომების უმეტესობა თავისით ქრება.

რას გვეუბნება ქართული — და სად გვატყუებს

ქართულს პირობითი წინადადებების საკუთარი, საკმაოდ ზუსტი სისტემა აქვს — და ეს კარგი ამბავია. რეალურ პირობას „თუ“ გამოხატავს — „თუ დრო მექნება“ — და ეს first conditional-ს შეესაბამება. არარეალურს — „რომ“ + კავშირებითი: „რომ ვიცოდე“ (აწმყოს კავშირებითი) second conditional-ია, „რომ მცოდნოდა“ (მეორე თურმეობითი) — third. ანუ თუ ქართულად „რომ“-ით იტყოდი, ინგლისურად would გჭირდება; თუ „თუ“-თი — will (ხოლო ზოგადი ფაქტისას, zero-ში, — უბრალოდ Present Simple).

ორ ადგილას კი ქართული გვატყუებს. პირველი — მომავალი დრო პირობაში („თუ დრო მექნება“), რომელიც If I will have-ს გვაწერინებს. მეორე — შედეგის ნაწილი: ქართულად „გეტყოდი“ ხშირად ერთნაირად ჟღერს ორივე შემთხვევაში — „რომ ვიცოდე, გეტყოდი“ და „რომ მცოდნოდა, გეტყოდი“. ინგლისურში კი ეს ორი სხვადასხვა ფორმაა: I'd tell you და I'd have told you. ამიტომ, როცა წარსულზე ლაპარაკობ, შედეგშიც have ჩაამატე — ქართული ამას არ შეგახსენებს.

Mixed conditional — როცა წარსული აწმყოს ეხება

ცხოვრება ყოველთვის ერთ დროში არ ჯდება: ხშირად წარსულის პირობას აწმყოში აქვს შედეგი. ამისთვის მესამე და მეორე ტიპი ერთმანეთს ერწყმის — პირობა Past Perfect-ით, შედეგი would + ზმნით; ან პირიქით — მუდმივი პირობა Past Simple-ით, შედეგი would have + V3-ით.

✅ If I had listened to you, I wouldn't be in this mess now. — შენი რომ დამეჯერებინა, ახლა ამ დღეში არ ვიქნებოდი.
✅ If she weren't so shy, she would have asked him. — ასეთი მორცხვი რომ არ იყოს, ჰკითხავდა. (მუდმივი თვისება → წარსულის შედეგი)

ეს კომბინაცია მაშინ გამოგდის ბუნებრივად, როცა ოთხივე ძირითადი ტიპი უკვე ავტომატურად გაქვს — ამიტომ ჯერ ამ სიას დაუბრუნდი, mixed conditional-ს კი B2 დონეზე მიხედე.

შეამოწმე თავი

ჩასვი ზმნა სწორ ფორმაში. ყურადღება მიაქციე კონტექსტს — ის გეუბნება, რომელი ტიპია.

1. If you ______ (mix) blue and yellow, you get green.
2. If it ______ (rain) tomorrow, we'll stay at home.
3. If I ______ (be) you, I'd talk to her today.
4. If we ______ (leave) earlier yesterday, we wouldn't have missed the train.
5. If I ______ (have) more free time, I'd learn Spanish — but I don't.

პასუხები: 1. mix — ზოგადი ფაქტი, zero. 2. rains — რეალური მომავალი, first (is raining-იც სწორია); will rain არა. 3. were — წარმოსახვითი აწმყო, second (სასაუბროდ was-საც გაიგონებ). 4. had left — წარსული, third; უბრალო left საკმარისი არ არის. 5. had — second: but I don't გეუბნება, რომ ეს ახლა არ მაქვს, ანუ არარეალური აწმყოა.

ერთი პრაქტიკული რჩევა: როცა if-წინადადებას წერ ან ამბობ, ჯერ საკუთარ თავს ჰკითხე — ქართულად „თუ“-ს ვიტყოდი თუ „რომ“-ს? „თუ“ = zero ან first (will მხოლოდ შედეგში), „რომ“ + კავშირებითი (ვიცოდე, მცოდნოდა) = second ან third — და მერე მხოლოდ ერთი რამ გადაწყვიტე: აწმყოა თუ წარსული. თუ if-ის შემდეგ will-ის ცდუნება არ გტოვებს, მომავალი დროის სამ ფორმაზე სტატიაში ეს წესი სხვა კუთხითაა ახსნილი; Past Perfect-ის მესამე ფორმა (V3) კი იგივეა, რაც Present Perfect-ში — თუ ის ჯერ განმტკიცებული არ გაქვს, Present Perfect-ისა და Past Simple-ის სტატიით დაიწყე. და თუ გინდა, რომ ამ სიაზე შენივე წინადადებებით ვივარჯიშოთ, სწორედ ამისთვისაა ინგლისურის ინდივიდუალური ონლაინ გაკვეთილები.

ხშირი კითხვები

რამდენი ტიპის პირობითი წინადადებაა ინგლისურში?

ოთხი ძირითადი: zero (ფაქტი — If you heat ice, it melts), first (რეალური მომავალი — If it rains, we'll stay at home), second (წარმოსახვითი აწმყო — If I had more time, I'd learn Spanish) და third (არარეალური წარსული — If I had known, I'd have come). არსებობს mixed conditional-იც, რომელიც წარსულის პირობას აწმყოს შედეგთან აერთებს.

რატომ არის „If I will have time“ შეცდომა?

ინგლისურში if-ის შემდეგ მომავალი დროის აზრს Present Simple გადმოსცემს, will მხოლოდ შედეგშია: If I have time, I'll call you. ქართული „თუ დრო მექნება“ მომავალ დროს იყენებს და სწორედ ეს გვაწერინებს ზედმეტ will-ს.

შეიძლება თუ არა would-ის გამოყენება if-ის შემდეგ?

ჩვეულებრივ არა. If I would know და If I would have known შეცდომებია; სწორია If I knew (second conditional) და If I had known (third conditional). would მხოლოდ შედეგის ნაწილში დგას.

როგორ შეესაბამება ინგლისური conditionals ქართულ პირობით წინადადებებს?

რეალური პირობა „თუ“ + მომავალი (თუ დრო მექნება) first conditional-ია. არარეალური „რომ“-კონსტრუქცია: „რომ ვიცოდე“ second conditional-ს შეესაბამება, „რომ მცოდნოდა“ — third-ს. ხაფანგი ისაა, რომ შედეგის ნაწილი ქართულად ხშირად ერთნაირია („გეტყოდი“), ინგლისურად კი განსხვავდება: I'd tell you / I'd have told you.
